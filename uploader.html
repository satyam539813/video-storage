GitHub Media Uploader

Checking local proxy…

Auto mode: images go to the repository media/ folder (up to 20 MB), everything else becomes a release asset through the local proxy (up to 2 GiB each, no total cap). Release uploads need the proxy because GitHub's upload host sends no CORS headers; the proxy uses your local gh login, so no token is needed for them. Repository uploads need a token with Contents: Read and write.
